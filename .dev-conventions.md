# Development Conventions

## Commit Style
- Concise messages describing WHAT changed, not HOW
- Frequent small commits per logical unit
- Format: `feat: <description>` or `fix: <description>`

## Code Quality
- Type hints on all public functions/methods
- Google-style docstrings for all public APIs
- ruff linting + mypy type checking before commit
- No emojis, no unnatural language in comments/specs

## Project Structure
```
backend/
  main.py          # FastAPI application entry point
  routers/         # REST endpoint handlers
  models.py        # SQLAlchemy database models
  services/        # Scanner engine + business logic
frontend/
  index.html       # Dashboard HTML
  dashboard.js     # Chart.js visualization
  styles.css       # CSS styling
tests/             # pytest coverage ≥80%
docker-compose.yml # Local dev setup
```

## Scope Boundaries
- Static analysis only (SQLi, XSS, secrets, outdated deps)
- No cloud deployment until approved
- Docker Compose for local development only
